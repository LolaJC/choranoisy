# Choranoisy — site statique
Site statique pour Choranoisy, choeur adulte de Noisy-le-Sec.  

## Faire fonctionner l'envoi du formulaire
Le formulaire fonctionne grace à https://web3forms.com. Il faut renseigner la clef d'accès dans `contact.html`.

## Fichiers
```
index.html, qui-sommes-nous.html, contact.html,
politique-de-confidentialite.html, 404.html
assets/css/style.css     Toute la mise en forme
assets/js/main.js        Lightbox, scroll, en-tête, envoi du formulaire
assets/img/               Logo et photos
```
